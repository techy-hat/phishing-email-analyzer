    How it works

    Three steps from submission to threat report.

      Submit email content

      Paste the raw email text — headers and body — or upload a .eml or .txt file directly.

    2. 2
      Indicator analysis

      The engine checks 40+ signals: sender domain alignment, URL structure, credential-request language, header spoofing, and attachment risk.

    3. 3

      Results include a risk score (0–100), per-indicator findings with severity ratings, and a clear security recommendation.

    About PhishGuard

    PhishGuard is a static analysis tool for identifying phishing indicators in email content. It examines sender domain alignment, embedded URL patterns, urgency and manipulation language, credential-request phrasing, attachment indicators, and header anomalies.

    Email content is sent to the local FastAPI backend for analysis and is never stored or logged. PhishGuard is intended as a supplemental tool — it does not replace a full security stack.

    Input formats .eml, .txt, plain text paste
    Data retention None — analysis is local only
    Indicators Sender, URL, content, attachment
    Backend required Yes — FastAPI on port 8000
